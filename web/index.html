Запросить случайный прокси

Без фильтров — любой действующий прокси. Можно указать регион, страну или оба фильтра сразу. Просроченные прокси не выдаются.


      
Ответ

      
{
  "id": "…",
  "protocol": "http",
  "host": "proxy.example",
  "port": 10000,
  "username": "login",
  "password": "password",
  "url": "http://login:password@proxy.example:10000",
  "region": "europe",
  "country": "DE",
  "expires_at": null
}

      
Фильтры

      
region
europe, asia, northern_america, latin_america_and_caribbean, africa, oceania, world_mix, custom, unknown
country
Двухбуквенный код: DE, US, TR, XK или unknown.
protocol
http, https, socks4, socks5.
search
Часть хоста или логина.

      
Методы

      
GET /api/proxies/randomОдин случайный действующий прокси с паролем.
GET /api/proxiesСписок без паролей. По API-ключу — только действующие; в панели — все записи. page=1, per_page=50 (до 200).
GET /api/proxies/{id}Один действующий прокси с паролем по ID.
GET /api/proxies/exportTXT с паролями, без просроченных прокси. format=url по умолчанию; также credentials_at, csv, credentials_first, host_first.
PATCH /api/proxies/{id}Изменить срок действия: {"expires_at":"2027-01-01T00:00:00Z"} или {"expires_at":null}. Только сессия администратора. Возвращает запись без пароля, в том числе просроченную.

      
expires_at — дата и время в RFC 3339 с часовым поясом, null — без ограничения. В списке expired показывает, истёк ли срок. При импорте и проверке списка поле expires_at применяется ко всем новым прокси. В интерфейсе даты показаны в часовом поясе браузера.

      
Фильтры работают для списка, случайного прокси и экспорта. Все заданные фильтры должны совпасть. World Mix и Custom — сохранённые метки региона, не синоним «любой».

      
401 — неверный или отозванный ключ; 403 — действие запрещено; 404 — прокси не найден; 400 — неверные параметры. Пример ошибки: {"error":{"code":"not_found","message":"Proxy not found"}}. Сервис выдаёт сохранённые реквизиты; доступность и фактический IP прокси не проверяются.
